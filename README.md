## The line

> Error: keep-warm 14 hours. Your rice is now a brick. I kept it warm. That was the deal.

A rice cooker reports exactly what happened, in its own flat voice. It did its job perfectly — and that is the disaster. Dry wit, one pattern: the setup is an error code plus a duration (14 hours), the tension is the consequence ("Your rice is now a brick"), and the release is the machine reframing the failure as faithful execution.
